# BIP 2026 « Miroir Miroir » · modules interactifs

Biennale de l'Image Possible, Liège (17.10–13.12.2026). Un dossier par module, chacun est une app web
statique lancée en kiosk sur sa borne (écran Elo 1024×768).

| Dossier | Module |
|---|---|
| `module1/` | Test de personnalité FR/EN + étiquette imprimée (Dymo 59×102 mm) |
| `module2/` | 360° : photo par 4 caméras IP cachées, imprimée sur l'étiquette |
| `module3/` | Vide ton sac : faux scanner d'aéroport (GPIO + Pi Camera), effet rayons X, étiquette « CLEAR » |

Lancement automatique au démarrage : voir [`kiosk/`](kiosk/README.md).
